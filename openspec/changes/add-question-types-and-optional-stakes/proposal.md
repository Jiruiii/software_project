# Proposal

## Why

組員討論後決定允許不押，且簡答與下注可同時開啟。多人作答不應全靠人工判選擇題，因此增加單選題自動判分，並讓學生作答中看見本組累積分數。

## What Changes

- 下注新增 0（不押），預設不押；每個搶答單位有下注開關，與題型獨立。
- 老師在準備階段設定簡答或單選，單選需填選項及正解；開始後鎖定設定。
- 所有組別的單選答案由伺服器即時判定；簡答維持老師在關題後或結果階段批改，未判定不計分。
- 本組目前總分在活動內逐題累加，作答中可見；他組分數與排行仍在結束後公開。
- 舊活動、答案、下注分數保留；題組維持完整提交、共用下注及一次計分。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `classroom-scoring`：可不押、題型與下注設定、單選自動判分、本組即時總分。

## Impact

修改服務、HTTP 介面、教師設定及學生作答／分數畫面，更新操作說明與測試。新增資料欄位採相容遷移。不接外部 AI 判分、不新增授權需求；累積範圍先以同一場活動為界，不把同名的不同活動組別誤合併。
