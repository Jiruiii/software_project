## ADDED Requirements
### Requirement: 批改與老師答案共用題目選擇
系統 SHALL 在作答與批改及結果工作區使用單一題目選單，讓監看、結果題目與老師答案使用相同題號。選全部或尚未關閉題目時不可暗中編輯另一題；切換題目、分頁及輪詢須保留各題未儲存草稿，逐題模式未手動選題時隨當題切換。
#### Scenario: 選題一致
- **WHEN** 教師選擇第一題查看作答並填寫老師答案
- **THEN** 表格、結果及老師答案都以第一題為對象，不存在第二個獨立題目選單
#### Scenario: 全部與未開題
- **WHEN** 教師選全部或未關題，之後選回已編輯的題目
- **THEN** 前者提示選擇已結束題目，後者恢復原有草稿且不自行儲存
