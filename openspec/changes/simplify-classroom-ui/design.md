## Context
現有頁面以同一份活動狀態渲染老師、學生、同步與結果。原有瀏覽器驗收已涵蓋設定、批改、老師答案與草稿；沿用這些流程。
## Goals / Non-Goals
讓狀態及主要動作清楚，減少看答案之前的捲動。不改後端規則、驗證與資訊發布時機。
## Decisions
- 當題標籤依 round_open 呈現，活動結果統一稱作答結束；工作區待批改數僅包含 reviewable_questions，避免把尚不能批改的作答算進去。
- Google 狀態及重試仍直接可見，僅長篇說明使用 details 收合；計分說明同樣保留為可展開內容，避免刪掉必要規則。
- 壓縮活動標題、收合的老師答案區、分數摘要與手機重複階段導覽；保留原有欄位、草稿及 keyboard focus。
- 「前往批改」只在其他工作區顯示，避免已在批改頁時仍顯示相同入口。
## Risks / Trade-offs
收合說明可能較難發現 → 使用明確摘要名稱，錯誤及待批改狀態不收合。精簡間距可能壓縮點擊範圍 → 維持主要按鈕可點擊並檢查桌面、390 px 與 320 px 手機。
## Migration Plan
無資料遷移；重新整理載入新版前端。回退前端檔案即可還原。
