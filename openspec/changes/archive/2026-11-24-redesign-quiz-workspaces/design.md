# Design

## Context

課程頁以雜湊路由和 Firebase 帳號切換工作區。活動頁定時取得含權限與公布限制的狀態，學生看到本組答案與報告，教師共用選題器驅動監看、結果及參考答案。

## Goals / Non-Goals

將選課、找活動和批改集中到可直接操作的位置。維持既有後端計分、題組、目錄導覽與 Google 權限。

## Decisions

- 品牌只顯示「課堂搶答」，保留課程內建立搶答活動的既有路徑。移除管理員舊活動頁、首頁相關查詢及 claim 寫入分支，沿用資料表且無須遷移。
- 卡片列使用原生橫向捲動與定位，滑鼠可用方向按鈕，學生已結束且未參與的卡片保持唯讀。定時刷新保留捲動位置與鍵盤焦點。
- 教師桌面左欄以原有題號、題幹與學習單連結供查閱，右欄為監看與批改。窄版保留精簡進度並就地操作。進度以伺服器回合狀態計算，查看題目沿用共用選題器。
- 結束按鈕放在主畫面，沿用確認對話框；學生或助教不得主持。
- 本組作答與報告直接使用 API 公布的判定。首次顯示既有成績為靜態，後續更新使用瀏覽器原生動效。

## Risks / Trade-offs

題組可含多個子題，回合以題組為單位，批改仍以子題為單位。長題號、手機寬度、輪詢和課後改判需以瀏覽器驗收。
