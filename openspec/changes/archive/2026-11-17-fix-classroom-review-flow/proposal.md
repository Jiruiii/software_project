# Proposal
## Why
目前改判不更新保底累計，雲端寫入後讀回中斷又改判會卡住；兩個題目選單容易造成填錯題，作答結束時未批改完的分數也容易被誤認為最終成績。需要修復這四項流程問題，讓課堂操作與狀態一致。
## What Changes
- 依最新判定重算保底，凍結已開放題目的先答資格。
- 寫入前保存同步意圖，重試與重啟時安全核對已寫入內容。
- 批改與老師答案共用一個題目選單，保留每題草稿。
- 作答結束後明示暫時成績與待批改數，全部批改後自動顯示批改完成。
- 依使用者要求保留待批改答案寫回規則與現有分組方式。
## Capabilities
### New Capabilities
無。
### Modified Capabilities
- `quiz-session`：改判後保底重算。
- `classroom-scoring`：暫時成績標示。
- `guided-notes`：同步中斷恢復。
- `teacher-workflow`：共用題目選擇。
## Impact
增量保存逐輪參與與先答紀錄、來源同步意圖，調整 API 狀態、教師畫面、學生報告與測試，不增加外部服務。
