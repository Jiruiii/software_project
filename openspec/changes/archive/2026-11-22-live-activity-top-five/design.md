# Design

## Context

學生答題頁依活動代碼取得定期更新的快照。伺服器已在快照內計算各組已公布分數，結果頁以同一套函式計算競賽名次。

## Goals / Non-Goals

學生能留在作答頁查看本次活動前五組，點閱或更新側榜時保留目前的作答草稿與焦點。

## Decisions

- 僅在活動進行中的學生快照重用本場計分與排名，先排全部參加組別再截前五列。回傳名次、組名、合計，不附下注明細、他組作答或保底身分。
- 逐題模式只加已關題的成績；全題模式在結束前為零。結束後由原有完整排行榜接手。
- 小卡放在現有活動側欄，於手機單欄排列時可收合。使用原有快照輪詢，只在榜單內容變動時替換排名列。

## Risks / Trade-offs

第五列遇到並列時按既有組名排序截斷，確保作答區維持緊湊。尚無題目公布成績時各組暫列零分，卡片說明公布時機。
