## Context

批改 API 的 displaced 與 candidate 已足以判斷被踢開和遞補的小組。回饋位於被批改儲存格，復原按鈕在動畫區外。

## Goals / Non-Goals

讓批改者看清組名、踢擊與遞補的先後順序。維持既有批改判定、復原與鍵盤流程。

## Decisions

- 使用約 1.5 秒的局部動畫。紙張先靜止約半秒，球鞋隨後接觸紙張，再把紙踢離。沿用紙張、球鞋與介面既有的判錯色。
- 桌面將動畫寬度限制在容易掃視的範圍，窄欄以欄寬縮放。動畫與靜態結果共用同一區域，結束時不移動按鈕或其他列。
- 完整組名與伺服器確認的遞補結果留在文字層。減少動態時直接呈現結果。

## Risks / Trade-offs

較長的回饋可能與下一次批改重疊。沿用單筆批改回饋的替換機制，讓新的判定直接接手。
