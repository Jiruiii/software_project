# Proposal

## Why
保底先答的三秒很短，學生看著題目或準備輸入時，容易錯過畫面上的倒數。讓學生選擇以輕柔的心跳聲跟著粉筆線數拍，可以用聽覺掌握還剩多久，也方便同一教室裡想安靜作答的同學。

## What Changes
- 學生在活動頁可開啟保底倒數心跳聲。三秒內每秒一組輕柔雙拍。
- 聲音跟隨剩餘時間，支援中途開關、頁面可見狀態及活動切換。

## Capabilities
### Modified Capabilities
- `quiz-session` 的保底倒數新增選用的聲音提示。

## Impact
影響學生端活動頁與倒數音效資源。作答權限沿用伺服器的保底期限。
