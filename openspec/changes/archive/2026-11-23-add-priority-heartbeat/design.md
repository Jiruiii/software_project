# Design

## Context
逐題保底和全題跨場保底使用同一個伺服器期限，前端按活動及期限辨識每次倒數。

## Goals / Non-Goals
學生可在等待開場時預先開啟音效，課堂中隨時靜音。音效只提示保底先答的三秒。

## Decisions
- 使用同站三秒單聲道 WAV，保留兩次鼓動之間的呼吸空間，第二下較輕。開關預設關閉，在同一活動頁內沿用。
- 使用者開啟開關時初始化 Web Audio。以粉筆線相同的剩餘時間建立單調時鐘期限，從對應音軌位置播放。重複的狀態更新不重啟播放。
- 關掉音效、切換活動、頁面隱藏或收到保底結束狀態即停止播放。分頁重新可見時只播放尚餘的部分。

## Risks / Trade-offs
音軌載入或瀏覽器音訊啟動可能晚於第一拍；已過的部分直接跳過。音效不可用時仍可讀取倒數、作答與重試開啟聲音。
