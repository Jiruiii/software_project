## 驗收紀錄
- 本機 Chrome 的 `cross-priority` 測試以兩個學生分頁與教師分頁確認預設靜音、中途啟用、輪詢去重與期限結束後可交卷。以實際解碼與 Web Audio 播放節點驗證音軌位置；模擬分頁隱藏、載入失敗、延遲與關題，並驗證停止及重試。
- 本機 Chrome 的 `motion` 與 `flow` 測試通過；Python 應用程式測試 139 項通過。瀏覽器測試在隔離資料上透過本機程序轉送 HTTP 請求。
- PCM 檢查確認音軌為 24 kHz 單聲道，長 3 秒。三組雙拍皆為第一拍較強、第二拍較輕，樣本峰值為 −15.4 dBFS。
