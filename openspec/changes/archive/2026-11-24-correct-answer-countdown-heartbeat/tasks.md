## 驗收紀錄

- Chrome 的 `browser-cross-priority.js` 以 11 秒全題活動與兩題各 6 秒的逐題活動，記錄實際 Web Audio 音軌啟停。兩種模式都在畫面顯示「剩餘 3 秒」時首次播放。全題開場先答期間靜音，逐題提早關題後停止，下一題獨立計時。
- 同套測試驗證不限時、預設靜音、途中開啟、分頁隱藏與恢復、音檔載入失敗及過期回應。倒數不因輪詢重播。
- `browser-question-timing.js`、`browser-motion.js` 與 141 項 Python 應用程式回歸測試通過。本機 HTTP 測試使用記憶體傳輸。
