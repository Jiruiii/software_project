# Design

## Context

活動內組別 ID 僅在單場有效。課程的 attendance 紀錄將每場組別連到固定的 team，原計分函式已處理押注、搶答分、待批改及舊計分制。

## Goals / Non-Goals

沿用逐題保底的期限與名單、單題及題組的收件流程。教師可選擇特定已結束場次，無須改變舊活動或課程排行榜。

## Decisions

- 在 activity_options 增加可空白的來源活動 ID，舊資料預設空白；逐題設定與全題來源互斥。
- 只提供同課程授課教師可選的已結束場次。準備中可儲存、清除來源，開始時再次檢查。學生與助教不取得設定選項。
- 只比較兩場均有 attendance 的課程小組，以來源場次當下已公布的押注分加搶答分取最低；有出席無得分者計零，新組與完全沒有前場紀錄者不列入比較。若無任何可比組別，省略等待期。
- 在開始活動的同一筆交易保存本場組別 ID 與 started_at 加三秒的絕對期限。活動結束或作答期限到達優先於保底。畫面與單題／題組收件使用同一份快照。
- 保留本機舊版預設及原逐題行為。已分配到課程的舊場次如無小組對應，適用無可比組別的規則。

## Risks / Trade-offs

同課程可能有同名場次，選單顯示日期與活動名稱。以前場小組參與紀錄為依據，不從學生顯示名稱推測重組前的身分。已結束但仍可改判的來源以本場開始時的成績為準。
