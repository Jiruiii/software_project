# Design

## Context

活動頁會依身分顯示課程碼或活動碼，現有字級與字距在窄側欄不足以容納十碼。舊版教師活動清單整列是導覽按鈕。

## Goals / Non-Goals

所有可分享的代碼使用一致的複製操作。加入課程與活動的填寫流程維持原樣。

## Decisions

- 共用代碼顯示元件，使用原始值複製。活動碼與課程碼沿用各頁目前選用的值。
- 清單的導覽和複製使用獨立按鈕；活動快照輪詢保留相同代碼的元件與操作焦點。
- 優先使用瀏覽器剪貼簿介面，受限時嘗試複製選取文字，仍無法複製時保留選取並提示手動操作。
- 標籤、值與按鈕可依實際容器寬度換列，長 UID 可以換行。

## Risks / Trade-offs

剪貼簿權限依瀏覽器而異，成功提示須在確認寫入後才顯示。
