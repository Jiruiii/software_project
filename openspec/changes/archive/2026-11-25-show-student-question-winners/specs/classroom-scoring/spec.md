## MODIFIED Requirements

### Requirement: E-05 判錯遞補
系統 SHALL 僅允許教師在已關閉的題目或結果階段將答案標為正確或錯誤。簡答初始為待批改且不自動加分，批次撤銷可還原先前狀態。教師的候選者為最早未被判錯的完整提交。待批改者明示待批改，該候選全部判對後學生端才公布組名。題組任一子題錯誤則整組候選退出，所有候選皆錯誤時無成功組別。Google 學習單依既有已關題寫回規則自動同步。

#### Scenario: 遞補與撤銷
- **WHEN** 第一順位被判錯，之後又改回正確或撤銷批次批改
- **THEN** 候選順序隨最新判定更新。學生端只有在當前候選全對時公布組名。原答案與收件時間不改動，已關題學習單自動同步。

#### Scenario: 未授權判分
- **WHEN** 學生或教師對作答中的題目嘗試判分
- **THEN** 拒絕並保持答案與分數不變。

#### Scenario: 兩種判定操作
- **WHEN** 教師查看任意題型的批改介面或送出未判定判定
- **THEN** 介面僅提供正確與錯誤按鈕，未判定 API 被拒絕，尚未批改內容顯示待批改。
