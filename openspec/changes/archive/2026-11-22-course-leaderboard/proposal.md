# Proposal

## Why

學生目前可以查看本組的課程累計分數，老師和學生也需要在同一門課中比較各小組跨活動的表現。

## What Changes

- 老師和學生可以從右側目錄查看課程排行榜，並在有權限的課程之間切換。
- 各組依已公布的累積分數排名，同分並列，後續名次按排在前面的組數計算。批改或改判後，開啟中的榜單會自動更新。

## Capabilities

### New Capabilities

- `course-leaderboard` 規範各課程的小組累積排名、讀取權限及更新時機。

### Modified Capabilities

## Impact

新增課程帳號 API 與工作區頁面，重用活動計分與排名規則。資料取自既有小組、出席及作答紀錄。
