# Design

## Context

課程帳號使用 SQLite 的小組及出席紀錄連結各場活動。課程紀錄已使用活動的公布規則計分，工作區與活動頁共用右側目錄。

## Goals / Non-Goals

課程榜顯示跨活動的累積名次。每場活動仍有各自的成績公布流程。

## Decisions

- 帳號端點驗證課程擁有人或學生會籍；教學帳號僅可查自己建立的課程。
- 以小組 ID 與出席紀錄對應各場活動，沿用已公布得分及競賽排名函式。查詢時按活動一次計算所有出席組別的分數。未連結註冊小組的舊活動資料不以名稱推測歸屬。
- 只在顯示榜單時定期查詢。切換課程、離開頁面或登出時淘汰舊請求；連線恢復後重新取得當前榜單。

## Risks / Trade-offs

從現有紀錄當場計算可反映改判及搶答遞補。成本隨課程內的活動與答案筆數增加，因此同一頁面一次僅發出一個更新請求。
