# Proposal

## Why

連線較慢時，課程入口的登入區會留白。已登入的使用者若讀取課程失敗，只看得到錯誤。手機教師從右側目錄切換活動階段時，目錄還會蓋住更新後的內容。

## What Changes

- 讓登入準備、課程載入與可重試的錯誤都有清楚的提示。
- 手機教師從目錄操作活動時，收合目錄並將焦點移到目前的工作。結束活動仍須確認。
- 校正既有的建立活動、多人結果和 Sheets 瀏覽器驗收，使腳本經由現行使用者入口驗證原有行為。
- 修正官方唯讀範本在活動內仍提示連線或重試同步的問題，直接說明如何取得可寫入的副本。

### New Capabilities

### Modified Capabilities

- `teacher-workflow` 的跨頁工作區新增入口狀態回饋與手機活動操作規格。
- `guided-notes` 明確區分官方範本與可重試的同步失敗。

## Impact

影響課程首頁、共用導覽、活動控制及前端驗收。沿用現有登入、活動及計分 API。
