# Spec Delta

## MODIFIED Requirements

### Requirement: 開始前儲存與錯誤定位
系統 SHALL 在教師按「開始搶答」時先驗證並儲存尚未儲存的活動及題目設定；任一步驟失敗不得開始搶答，並顯示原因及對應設定位置。準備階段只提供上方一個「儲存設定」按鈕作為不開始活動的集中儲存入口，不另設活動規則或單題儲存按鈕。

#### Scenario: 有效設定與無效設定
- **WHEN** 教師修改活動規則與單選設定後直接開始，或單選設定缺少正解
- **THEN** 有效設定儲存完成後才開始；無效設定維持準備中並展開錯誤題目供修正

#### Scenario: 唯一儲存入口
- **WHEN** 教師在活動設定與題目設定之間切換
- **THEN** 只顯示上方「儲存設定」作為儲存入口，「開始搶答」為另一個清楚的動作；下一步只切換設定頁，不會開始活動
