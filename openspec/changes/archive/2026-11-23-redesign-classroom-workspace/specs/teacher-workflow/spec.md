# Spec Delta

## ADDED Requirements

### Requirement: 跨頁一致的課堂工作區
系統 SHALL 以一致的品牌和可辨識的主要動作連接課程首頁、活動頁與設定說明。登入時應直接提供身分與登入控制；已登入的課程和活動清單應能分別辨識名稱、角色或階段。桌面及手機應能使用原有導覽、表單、作答和批改。

#### Scenario: 從登入進入課程與活動
- **WHEN** 使用者選擇身分登入，並從課程清單進入課堂活動
- **THEN** 各畫面提供可辨識的中文標題與操作，清單可區分名稱與其他資訊，原先有權限的功能仍能從工作區到達

#### Scenario: 手機與鍵盤操作
- **WHEN** 師生以 390 px 手機或鍵盤操作工作區
- **THEN** 行動導覽仍可展開，聚焦的操作有可見指示，長內容留在可換行或局部捲動的區域
