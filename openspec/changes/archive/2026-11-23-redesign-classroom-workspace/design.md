# Design

## Context

兩個入口共享 style.css，部分工作區由 courses.js、workspace.js 與 app.js 動態建立。既有瀏覽器案例以可及名稱、欄位 ID 與右側導覽位置操作。

## Goals / Non-Goals

讓師生進站能直接辨識要完成的事。工作範圍以呈現層為限，沿用既有的權限與計分規則。

## Decisions

- 以「課間」字標和中文標題統一兩個入口。以教室素材塑造入口，表單採用易讀的淺色底。進入活動後減少裝飾，把空間留給題目、答案及場次操作。
- 保留原本的身分選擇、表單、右側導覽與手機收合行為。課程名稱、身分、階段、分數使用獨立文字元素，可隨窄螢幕換行。
- 沿用單一靜態樣式表及裝置可用中文字體。導覽和表單不依賴外站圖庫、字型服務或新增的前端框架。

## Risks / Trade-offs

既有 CSS 包含不同角色、活動階段與視窗寬度的覆寫。以改版前後的控制項清單、瀏覽器操作、截圖和窄螢幕尺寸量測核對。
