# Spec Delta

## Purpose

讓教師與學生在活動結束後回顧可核對的課堂紀錄，提供安全的資料下載、依伺服器收件時間重播與答案比較，並維持學生只能看到本組紀錄及已公布結果的隱私界線。

## ADDED Requirements

### Requirement: E-01 教師活動 CSV
系統 SHALL 僅允許教師在結果階段下載 UTF-8 BOM CSV，包含題號、題組、組別、答案、收件時間、相對秒數、原始搶答順位與成功狀態；無人作答也有明確紀錄，文字不得觸發試算表公式。

#### Scenario: 完整且安全的匯出
- **WHEN** 結束活動含多組答案、逗號、換行或等號開頭文字
- **THEN** CSV 可還原各欄位且有正確順位，危險字串作文字處理

#### Scenario: 權限與階段
- **WHEN** 學生或尚未結束活動嘗試下載教師 CSV
- **THEN** 伺服器拒絕，不洩漏其他組資料

### Requirement: E-03 教師搶答回放
系統 SHALL 在結果階段讓教師選題並播放、暫停、重播收件時間動畫，顯示每組相對作答時間與最後成功組別；相同時間依伺服器序號排序，不修改原始紀錄。

#### Scenario: 回放順序
- **WHEN** 教師選擇已有多人作答的題目播放
- **THEN** 各組依實際收件秒數出現，暫停保持進度，重播由零開始

### Requirement: E-06 相同及相近答案歸類
系統 SHALL 僅向教師提供逐題答案歸類，忽略全半形、大小寫及多餘空白判斷相同，相近文字以明示門檻分群並標示「文字相近，不代表同義或正確」，不使用 AI API 或自動判分。

#### Scenario: 不變更原始答案
- **WHEN** 教師查看大小寫或空白不同的答案
- **THEN** 顯示於同一分類但保留原文與組別，判分仍由教師決定

### Requirement: E-07 本組學習報告
系統 SHALL 在結果階段讓學生查看並下載本組 CSV 報告，逐題包含本組答案、老師判定、下注、單位得分、是否成功及老師填寫的參考答案；未作答和未判定需明示，不含他組非公開答案。

#### Scenario: 報告隔離
- **WHEN** A 組查看或下載報告
- **THEN** 只取得 A 組紀錄與公開參考答案，即使偽造組別參數也不能取得 B 組報告
