# Proposal

## Why

本機 15 項核心已完成，使用者要求依原功能表逐項實作 E-01～E-11，讓課堂除了搶快，也能判分、回顧與匯出學習成果。保留既有活動與基本模式，新增功能有規格、測試及各自提交。

## What Changes

- E-01 活動 CSV；E-03 教師逐題動畫回放；E-06 文字正規化與相近答案歸類。
- E-02 可選逐題模式；連續三題未搶答成功組別，下一題先答三秒。題組視為一個搶答單位。
- E-04 每次提交下注 1～3 分；E-05 老師判錯後依序遞補；E-10 每組答對加下注分、答錯扣下注分，未判定零分，結果階段公布排行。
- E-07 老師填參考答案，學生查看／匯出本組報告；E-08 核對並加強斷線重連與草稿恢復。
- E-09 支援官方題組範本，題組全部子題原子送出，同一組別整組搶答成功，原位寫回各子題。
- E-11 教師設定秒數，伺服器控制到期結束；逐題模式到期關閉當題，最後一題到期結束活動。
- 既有全題開放與未判分活動仍依收件順序顯示成功組別；保底資格只在逐題模式計算。結果階段的人工判分不回溯改動已使用的保底資格。

## Capabilities

### New Capabilities

- `classroom-review`: CSV、動畫回放、答案歸類、小組報告與下載。
- `classroom-scoring`: 下注、教師判定、遞補、參考答案與排行榜。

### Modified Capabilities

- `quiz-session`: 可選逐題／保底／倒數、題組提交、結果公開範圍及重連恢復。
- `guided-notes`: 題組動態辨識、預覽、匯入及所有子題寫回。

## Impact

修改 quiz_service.py、app.py、guided_notes.py、google_sheets.py、前端與測試。沿用 Python 標準函式庫、SQLite 與本機 HTTP；新增資料表／欄位採向前相容遷移，不清除既有活動。仍不部署公網、不接 AI 判分服務。Google 真實題組驗收只建立專用測試表。
