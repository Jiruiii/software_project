# Design

## Context
活動頁定時更新，監看表可能重建。題組以完整且所有子題皆未判錯的第一組為候選，跨場和逐題先答共用伺服器截止時間。

## Goals / Non-Goals
讓課堂中正在操作的人看懂判定、交卷及開放時間。保留表格、鍵盤操作與既有帳號的資料可見範圍。

## Decisions
- 單筆批改在同一交易取得前後候選並保存可復原紀錄，沿用批次復原的擁有者與版本檢查。只在本分頁收到成功回應後播放一次；切換活動、競態失敗、初始讀取及輪詢不得誤播。
- 透過目前學生與既有提交者紀錄的比較辨認隊友，僅傳送布林值。既有匿名資料使用本組收件提示。
- 優先線依伺服器剩餘時間縮短，到期重新取得可作答狀態。完成計分的前三名沿用名次與並列規則。按偏好減少動態時保留全部文字。

## Risks / Trade-offs
逐題關閉後也能批改。候選必須從伺服器取得，以避免題組和同時批改的結果不一致。暫時成績不適合提前慶祝。
