# Design

## Context

已有 saveAllSettings 共用驗證與儲存；問題是多餘的局部按鈕，而非缺少功能。

## Goals / Non-Goals

**Goals:** 唯一儲存入口，維持未儲存狀態提示與開始前檢查。

**Non-Goals:** 不改為自動儲存，不改後端與參考答案編輯。

## Decisions

移除局部提交按鈕與處理器，表單 submit 只阻止預設導頁，避免 Enter 誤送出。上方儲存與開始繼續使用既有集中儲存流程。開始按鈕名稱只描述開始動作，未存提示清楚說明開始會先儲存。

## Risks / Trade-offs

舊測試點局部按鈕 → 更新為集中儲存入口，保留原有行為驗證；另檢查準備頁只有一個名稱含「儲存」的可見按鈕。
