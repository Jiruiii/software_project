## Decisions
課程與活動共用同一份角色導覽，寬螢幕將常用連結放在品牌與頭像之間。課程專屬操作與網站管理工具各用可由鍵盤操作的下拉選單。1120 像素以下從右上角展開右側目錄，展開狀態與焦點隨版面切換更新。個人資料及登出集中於頭像。活動的關題與下一題控制始終留在目前回合狀態旁。管理員選擇歸屬課程時只顯示課名，同名附課程代碼，確認時可核對授課老師。

管理員目錄與頁面標題統一為「將未歸屬活動加入課程」。清單有活動時說明加入後的查看位置，課程選單提供可見標籤。確認訊息及完成回饋顯示活動和課程名稱；沒有待處理活動、仍需教師建立課程時各有對應提示。沿用原有管理員權限、網址及活動歸屬資料。

學生課程頁顯示實際所屬組別，退出時確認課程、組名及成績歸屬，成功後開啟預填課程代碼的加入表單。每次入組使用獨立識別值，既有成員在資料庫升級時補值。伺服器以登入 UID、課程與這次入組識別值核對退組，在同一交易移除成員關係及本人該課的學生工作階段。即使最後一人離開也保留小組、出席、送出者與分數。

伺服器驗證 Firebase Google ID token 的簽名、專案、簽發者、提供者與已驗證信箱，以 UID 識別。管理員 UID 由本機設定指定。課程擁有者以已註冊帳號授予助教權限；學生用課程代碼首次建立或加入小組，密碼加鹽雜湊。活動工作階段限於所屬課程及角色。舊場次由管理員逐場分配，不按同名組別合併。批改保留版本、操作者及時間。SQLite 需要持久化，不在本次部署雲端主機。

管理員名單合併既有 `adminUid` 及選填的 `adminUids` 陣列。伺服器統一以完整 UID 判斷管理權，前端沿用個人的 `admin` 欄位，不取得名單。調整本機設定後重新啟動即可套用。

## Validation

首頁清單可直接開啟具網址的課程頁。加入小組、建立小組、新增課程、歷史紀錄、管理員工具與課程管理各自使用獨立頁面。功能目錄由帳號權限及當前課程身分產生，手機由右上角展開。學生可查本組作答，助教可查學生作答並批改，僅授課教師可管理該課程。活動內的表單提交及答案判定跟隨所選內容。

登入前選擇只影響登入說明。登入後以 home 回傳的身分及授課清單決定導覽與首頁，包含尚未建課的教師與僅受邀為助教的帳號。歷史頁的「前往批改」以該課程的工作階段開啟指定活動的作答與批改頁籤，沿用題目可批改時機及版本檢查。

以 Google 帳號的課程成員關聯找組。重設只更新所選課程小組的 salt 與 digest，沿用建組的密碼規則。授課老師權限由伺服器判定。紀錄以課程、場次及組別關聯讀取已公布答案與判定。首頁及活動頁共用帳號導覽，桌面使用頂列，窄螢幕收合；Google 照片不可用時顯示名字首字。手動結束使用原生 dialog，預設焦點在返回按鈕，確認後才送出原本的結束請求。

離線測試使用內部測試身分邊界，不提供測試登入 HTTP 旁路。真實多帳號驗收須先完成 Firebase 專案設定。
