## Decisions
伺服器驗證 Firebase Google ID token 的簽名、專案、簽發者、提供者與已驗證信箱，以 UID 識別。管理員 UID 由本機設定指定。課程擁有者以已註冊帳號授予助教權限；學生用課程代碼首次建立或加入小組，密碼加鹽雜湊。活動工作階段限於所屬課程及角色。舊場次由管理員逐場分配，不按同名組別合併。批改保留版本、操作者及時間。SQLite 需要持久化，不在本次部署雲端主機。

## Validation
首頁清單可直接開啟具網址的課程頁。加入小組、建立小組、新增課程、歷史紀錄、管理員工具與課程管理各自使用獨立頁面。右側功能目錄由帳號權限及當前課程身分產生，手機由右上角展開。學生可查本組作答，助教可查學生作答並批改，僅授課教師可管理該課程。活動內的表單提交及答案判定跟隨所選內容。

登入前選擇只影響登入說明。登入後以 home 回傳的身分及授課清單決定導覽與首頁，包含尚未建課的教師與僅受邀為助教的帳號。歷史頁的「前往批改」以該課程的工作階段開啟指定活動的作答與批改頁籤，沿用題目可批改時機及版本檢查。

以 Google 帳號的課程成員關聯找組。重設只更新所選課程小組的 salt 與 digest，沿用建組的密碼規則。授課老師權限由伺服器判定。紀錄以課程、場次及組別關聯讀取已公布答案與判定。首頁及活動頁共用帳號導覽，桌面提供側欄，窄螢幕收合；Google 照片不可用時顯示名字首字。手動結束使用原生 dialog，預設焦點在返回按鈕，確認後才送出原本的結束請求。

離線測試使用內部測試身分邊界，不提供測試登入 HTTP 旁路。真實多帳號驗收須先完成 Firebase 專案設定。
