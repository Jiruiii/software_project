# Spec Delta

## MODIFIED Requirements

### Requirement: F-09 答案寫回原工作表
系統 SHALL 在雲端使用伺服器服務帳戶、本機桌面模式使用教師授權，在每輪關題、倒數關題、整場結束及已關題答案改判／撤銷後，於背景自動將已關閉題目的最快未判錯完整提交寫回來源原格，保留未關題、無關內容與格式。題組全部子題使用同一成功組；教師明確勾選的子題以老師答案優先寫回，取消後恢復候選或原值。無人作答或全錯時不新增答案；若曾寫入則核對後還原匯入原值。教師可查看同步中、完成或失敗與重試；無授權、來源變動或他人改格必須報錯。不能另建表冒充成功，未變更結果不重複呼叫 Google，雲端重啟後獨立恢復需要同步的活動。

#### Scenario: 已寫回答案被判錯
- **WHEN** 最快組已寫回後被判錯
- **THEN** 自動改寫第二快未判錯組；若全部被判錯，僅在答案格仍是系統上次寫入內容時還原原值，他人已修改則停止

#### Scenario: 成功回寫
- **WHEN** 已匯入且教師已授權的活動關閉一輪題目
- **THEN** 背景核對並寫回本輪與先前已關閉題目的成功答案，原 Sheet 識別不變，未關題格不更新，教師畫面呈現結果

#### Scenario: 來源位置變動
- **WHEN** 匯入後來源題號或填空格位置被移動
- **THEN** 系統偵測差異並停止寫回，要求重新確認對應

#### Scenario: 單題與有子題編號的作答區
- **WHEN** 老師預覽或匯入含單題、題組或兩者混排的學習單
- **THEN** 系統 SHALL 將單題對應到作答格左上角，有子題編號的列對應到編號右側同列的答案格。寫回、改判、重試及還原均使用此對應並保留編號。無法辨認的分欄題組及仍指向編號的舊對應應提示修正或重新匯入。

#### Scenario: 權限不足與答案公式
- **WHEN** 寫入權限不足，或答案內容以等號等試算表運算符開頭
- **THEN** 前者顯示失敗而非成功且課堂仍可繼續，後者以文字答案寫入而不執行公式

#### Scenario: 保護官方原範本
- **WHEN** 教師嘗試將答案寫回專題提供的官方範本 ID
- **THEN** 系統要求先複製為自己的學習單並重新匯入，不能修改共用範本

#### Scenario: 同步期間再改判
- **WHEN** Google 寫入期間又發生教師改判
- **THEN** 保留本次核對結果並再次排入最新結果，不能將舊寫入標為最新同步完成，慢速 Google 不阻塞學生作答

#### Scenario: 關閉瀏覽器與重啟
- **WHEN** 老師開始已授權活動後關閉瀏覽器，或重新啟動伺服器
- **THEN** 前者仍可在倒數關題後背景同步；雲端重啟後自動恢復核對及同步，本機桌面模式仍可重新授權並開啟活動

#### Scenario: 老師答案優先與取消
- **WHEN** 教師對已關閉題目儲存非空參考答案並勾選用老師答案更新學習單，或取消該選項
- **THEN** 前者背景寫回老師答案且後續改判不覆蓋它；後者恢復當下最快未判錯組的答案，無候選則核對後還原匯入原值。學生分數與成功者均不改變

## ADDED Requirements

### Requirement: 以課程授權學習單
伺服器 SHALL 核對私人副本中的課程標記，再向授課者提供預覽、匯入及寫回。公開原範本可試讀。教師登出後背景作業仍可寫入。

#### Scenario: 跨課程與撤回
- **WHEN** 私人副本缺少標記、屬於其他課程或分享權限已撤回
- **THEN** 系統停止該操作，保留原格並顯示可修正的原因

### Requirement: 貼上可編輯的共用連結
系統 SHALL 讓授課老師貼上已開放「知道連結的任何人」編輯的副本網址，無須另外共用給服務帳戶或建立課程分頁。匯入時自動記錄所屬課程，保留原格寫回及既有私人副本的授權機制。

#### Scenario: 預覽及綁定
- **WHEN** 授課者提供可透過連結編輯的副本並確認匯入
- **THEN** 網站在建立活動時綁定目前課程，拒絕其他課程再次佔用同一份副本

#### Scenario: 編輯權變更
- **WHEN** 預覽、匯入或寫回時，共用連結只允許檢視、留言或已撤回
- **THEN** 連結模式顯示授權錯誤，保留原表內容，恢復編輯權後可以重試
