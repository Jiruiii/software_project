## MODIFIED Requirements

### Requirement: 關題後提供老師答案
系統 SHALL 在逐題模式的該題關閉後，以及全題模式整場結束後，於教師主要工作區提供可選填的老師答案。支援單題與題組子題，儲存後立即公布於學生該題的老師正確答案區，並保留於整場結束後的本組報告，不改動作答、判定、順位或分數。教師可修改或清空；未關閉題目及學生不得編輯。輪詢與切換題目不得覆蓋尚未儲存草稿，畫面須區分未儲存與已儲存。

#### Scenario: 逐題補充與跳過
- **WHEN** 逐題搶答關閉本題，所有組別都答錯或無人作答
- **THEN** 教師可直接填寫老師答案，也可以不填繼續下一題；已關閉題目仍可選回編輯

#### Scenario: 全題模式與報告
- **WHEN** 全題模式結束活動後老師補充某題答案
- **THEN** 主要工作區可選題填寫，學生結果報告呈現最新參考答案，原有分數不變

#### Scenario: 權限與草稿
- **WHEN** 學生、未關題或不存在題號嘗試儲存，或教師在輪詢及切換題目期間編輯
- **THEN** 前三者遭拒絕；後者保留草稿且未按儲存前不更新參考答案或學習單

#### Scenario: 逐題公布與更新
- **WHEN** 該題已關閉且老師儲存、修改或清空參考答案
- **THEN** 所有本活動學生即使未作答也能在該題看到最新內容，清空後移除；下一題進行中仍可查看先前已公布答案

#### Scenario: 未關題不洩漏
- **WHEN** 題目尚未關閉或全題模式尚未結束
- **THEN** 學生 API 與畫面均不包含該題老師答案或選擇題答案鍵
