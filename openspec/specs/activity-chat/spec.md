# activity-chat Specification

## Purpose
讓同一場搶答的學生在作答期間使用小組名與其他組即時討論，明確限定誰能讀寫頻道、每則發言代表哪一組，以及整場活動結束時如何清除討論內容。

## Requirements

### Requirement: 學生共用頻道

系統 SHALL 在學生答題頁左下角提供本場共用頻道。伺服器 MUST 限制讀寫者為本場學生，並依其已驗證的小組署名。訊息依收件順序顯示，重新連線可取得本場先前的訊息，同一發言重送只保留一份。

#### Scenario: 跨組討論

- **WHEN** 同場一組發言且另一組開著頻道
- **THEN** 雙方會看到同樣的純文字訊息與發言小組名，學生可以收合頻道繼續答題。

#### Scenario: 身分及場次隔離

- **WHEN** 教學人員或其他場次的學生要求讀取或發言
- **THEN** 伺服器拒絕，不提供訊息；學生送來的顯示名稱不能變更發言署名。

### Requirement: 討論隨整場搶答結束

系統 SHALL 自搶答開始開放頻道，逐題關題及換題期間持續開放。手動結束、最後一題關閉或整場倒數結束時，MUST 同步刪除本場訊息並停止讀寫。

#### Scenario: 從開場到關場

- **WHEN** 活動處於準備中、逐題模式的兩題之間或已結束
- **THEN** 三個階段分別為無法讀寫、可繼續討論、訊息已清除且無法讀寫；其他活動的訊息不受影響。
