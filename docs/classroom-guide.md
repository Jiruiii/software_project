# 師生課堂操作

同一門課可以有多場搶答。學生在課程內固定加入一個小組，每場活動各自計分，課程排行榜再將各場已公布的分數累加。

## 開課與進入活動

| 身分 | 首頁與主要操作 |
| --- | --- |
| 管理員 | 從右側目錄授予教師資格，或將舊活動分配到課程。 |
| 授課老師 | 在「我的課程」新增或打開課程，分享課程代碼、建立活動、加入助教及重設小組密碼。 |
| 助教 | 在「我的課程」進入受邀課程，從「學生作答與批改」查看各組作答與批改歷程。 |
| 學生 | 在「我的小組」建立或加入課程小組，點選已有的組別後進入課程與活動。 |

課程與活動頁的代碼、舊版活動清單的活動代碼，以及「我的帳號資料」的 UID 旁都有「複製」。手機點右上角目錄展開功能。初次設定與帳號授權請見 [Firebase 設定](firebase.md)。

## 老師備課與開題

1. 在自己的課程選「建立課堂活動」。可以直接輸入名稱與題數，也可自訂題號或[匯入 Google Sheets 學習單](google-sheets.md)。
2. 在「活動設定」選全題同時開放或逐題搶答，作答時間可設 0～3600 秒，0 表示不限時。
3. 進入「題目與計分」，逐題填寫選填的題目文字、選擇題型及是否開放下注。題組可逐一設定子題。學生從開題時起看得到題目文字。

   | 題型 | 設定與判分 |
   | --- | --- |
   | 簡答 | 學生輸入文字，老師或助教在關題後判定。 |
   | 單選 | 每行輸入一個選項，共 2～8 項，指定一個正解，自動判分。 |
   | 多選 | 輸入 2～8 個選項，勾選所有正解。學生至少選一項，選取集合完全吻合才算正確，勾選順序不影響結果。 |

4. 按「儲存設定」或「開始搶答」一次檢查並儲存活動規則與題目。設定有誤時先修正畫面指出的題目。開始後鎖定題型、正解及下注設定。
5. 逐題模式用「關閉本題」及「開啟下一題」推進。手動結束整場會先要求確認；最後一題關閉或全題倒數到期則自動進入結果。

### 逐題保底先答

切換到逐題模式時預設啟用保底，老師可在開始前取消。每次開題以本場當時已公布的總分選出所有並列最低的小組，讓它們先答三秒。第一題大家都是零分，所有已加入的小組都能立刻送出。先答期間才加入的小組等三秒結束後即可作答。

開題後改判，當題的名單與期限維持到期滿，下一題再按新分數選組。伺服器重啟後沿用原期限。

### 全題模式跨場保底

在「活動設定」選「全題同時開放」，再從「跨場保底的成績來源」選擇本課程已結束的場次。按「儲存設定」或直接「開始搶答」即可套用。保留預設的「所有組別同時開始」即可關閉保底。

系統在本場開始時比較兩場都有參加的小組。來源場次總分並列最低的組別可立即回答任一題，其他小組三秒後可答。若沒有可對應的小組，大家同時開始。來源場次改判或晚加入本場均不會改變已經開始的三秒。[小組比對與計分範例](account-priority-backlog.md)

## 學生作答與公用頻道

- **作答與下注**　每組每題或題組只收第一份有效作答。下注預設 0，可選 1、2、3 分；老師關閉下注時固定為 0。題組要填齊所有子題一次送出，共用一筆下注。送出後答案與下注鎖定。
- **即時狀態**　未開放的題目顯示題號與等待狀態。作答期間，本組會看到已公布的押注分、搶答分與合計；已送出待關題與已關題待批改分開顯示。
- **小組討論**　活動開始後，左下角「公用頻道」開放給同場學生，各組發言自動署上登入組名。關題與換題之間仍可討論。整場結束時系統關閉頻道並刪除該場訊息，課後紀錄保留作答與批改。
- **中斷與回來作答**　同一分頁重新整理可恢復未送出的答案與下注；回應遺失時，相同內容重送會對應到原來的作答。名次以伺服器收到的順序計算。登出會清掉草稿，關閉分頁後請以「作答紀錄」確認已收件內容。用同一 Google 帳號重新登入可找回小組與已保存的紀錄。

## 得分與排名

每個計分單位的總分是押注分加上搶答分。以押 3 分為例，答對得 3 分，答錯扣 3 分。新制另依完整收件順序，對全對的前三組加 4、2、1 分。第四組答對仍得押注的 3 分；第一組即使押 0 分也能得 4 分搶答分。

題組全對才加押注分，任一子題判錯就扣押注分，其餘待批改情況暫計零分。逐題模式在當題關閉後公布，全題模式在整場結束後公布。簡答待判期間不加搶答分；老師改判會重算加扣分及前三組順位。計分改版前已開始的活動沿用其原規則。

| 在哪裡看 | 計分範圍與可見對象 |
| --- | --- |
| 答題頁或教師活動頁的「本場前五名」 | 只算本場已公布的分數，新場從零開始。最多顯示五組，同分以組名穩定排序後取五列。 |
| 活動結果的完整排行 | 列出本場所有參與小組，包含零作答組。待批改時標示暫時成績，全部判定後顯示批改完成。 |
| 右側「課程排行榜」 | 累計同一門課各場已公布的分數，包含零分與負分。教師可選自己建立的課程，學生可選已加入的課程，榜上標示自己的小組。 |

各榜單同分同名次，下一個名次按前面組數計算，例如 1、1、3。開著榜單時，關題、批改或改判後的成績會自動更新。

## 課後批改、回看與匯出

- **更正判定**　老師與受邀助教可以從「學生作答與批改」選課、展開活動，回看答案與批改歷程。關題後或活動結束後仍能判對、判錯或改判，原答案和收件時間會保留。同一筆答案已被別人批改時，重新查看最新紀錄再操作。
- **批次批改**　在「更多工具」比較同題的相似答案，門檻為 85%。原文完全相同的類別會預先勾選，其他答案可個別選取；超過 200 類後只比對相同文字。可以批次判對或判錯；若後續尚無其他批改，可撤銷該次批次操作。重新載入、登出或切換活動會結束原撤銷入口。
- **老師參考答案**　在「作答與批改」或「搶答結果」選一個已關閉的題目，展開「老師正確答案（選填）」。儲存後學生可見，切換題目會保留未儲存的老師草稿。勾選「用老師答案更新學習單」可指定 Sheets 的寫回內容，判分仍由批改操作處理。
- **回查與報告**　學生的「作答紀錄」可以按課程展開歷次活動。結果頁的本組報告列出原答案、判定、下注、得分與老師參考答案，可下載本組 CSV。教師可匯出活動 CSV，也可用重播查看各題原始收件順序。
- **收件時間與成功組別**　逐題計時從當題或題組開放時計起，包含三秒保底；全題模式從活動開始計時。舊紀錄若無法還原開題時間會標示計時基準。成功組別依最快且未被判錯的完整提交決定，改判後會遞補。這和必須全對才獲得的搶答加分有不同的判定條件。

## 舊版共用密碼入口

在尚未綁定 Firebase 的資料庫上，執行 `start-classroom.cmd --legacy` 或 `python app.py --legacy`。若要新建一份獨立測試資料，可加上 `--db data/legacy-test.sqlite3`。在啟動視窗設定非空白教師密碼，保留視窗並開啟 [本機課堂](http://127.0.0.1:8000)。

老師建立活動後可複製六碼活動代碼。學生另開新分頁，輸入活動代碼及組名；相同活動中輸入同一組名即可加入同組。測試不同組別時使用不同組名，直接開新分頁輸入網址以免複製到原分頁的登入狀態。需要跨堂保存帳號與固定小組時使用 Firebase 課程入口。
