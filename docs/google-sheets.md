# Google Sheets 學習單

手動建立題號可直接測試搶答；要把答案寫回試算表，請由老師在自己的課程選「建立搶答活動」，再切換到「匯入 Google 學習單」。

## Azure 伺服器寫回

老師在自己的學習單副本點「共用」，把「一般存取權」設為「知道連結的任何人」，角色選「編輯者」。複製連結，在授課頁貼上網址、預覽並建立活動，網站會記住副本所屬課程。每門課使用自己的副本；拿到這份連結的人也能直接修改表格。

伺服器在教師登出或服務重啟後仍可處理關題及改判；撤回連結編輯權會停止後續寫回，恢復後可按「重試同步」。原先分享給服務帳戶並以「課程設定」分頁 A1 標記課程的私人副本仍可照原方式使用。參閱 [Azure 部署指南](azure.md)。

## 本機桌面模式首次設定

1. 在 Google Cloud 建立專案，啟用 **Google Sheets API**。
2. 設定 OAuth 同意畫面，將準備登入的 Google 帳號加入測試使用者。
3. 建立 **電腦版應用程式（Desktop app）** OAuth 用戶端，下載 JSON。
4. 在專案內建立 `credentials` 資料夾，將下載的檔案改名並放到：
   ```text
   credentials/google-oauth-client.json
   ```
5. 進入教師頁，按「連線 Google」→「開啟 Google 授權頁」，登入並同意試算表存取。

教師頁的「首次設定說明」提供完整操作步驟。教師登出或伺服器重新啟動後，需要再次連線 Google。

負責匯入與寫回的授課老師需授權可編輯該副本的 Google 帳號。學生與助教使用課程工作區參與作答或批改。

真實 JSON、密碼與授權 token 不可放入公開 repository；下載程式不會附帶這些資料。Google 官方設定參考：[Sheets Python quickstart](https://developers.google.com/workspace/sheets/api/quickstart/python)、[OAuth 同意畫面](https://developers.google.com/workspace/guides/configure-oauth-consent)。

## 匯入與寫回

老師可直接使用自己的學習單。預覽時，單題會顯示合併作答格的左上角，例如 `G5:H5` 顯示為 `G5`。題組若在 G 欄列出 `（1）`、`（2）`，對應的答案格會顯示為 `H5`、`H6`。同一張表可混用兩種版面。若舊活動曾將答案寫進編號欄，請先在副本恢復原子題編號，再重新預覽並匯入。

1. 開啟[官方單題範本](https://docs.google.com/spreadsheets/d/12uh5xhIx2wXFMy42KU8lN7rLFQ8GDugt9zfAFEvu-1E/copy)，建立自己的副本。
2. 將副本網址貼到教師頁的「Google Sheets 連結」。
3. 按「讀取並預覽題號」，核對工作表、題數與答案格，再建立搶答活動。
4. 讓學生加入、開始搶答、送出答案，再由老師結束搶答。
5. 每輪關題後會自動寫回最快未判錯組別的答案，格式為「答案（組名）」；查看活動中的同步狀態，或開啟來源學習單確認。全題模式手動關題後即同步該單位，其餘開放中題目的儲存格保留原值。整場結束時同步剩餘題目。
6. 備課時可在「題目與計分」的子題下填寫參考答案，並勾選「關題後用老師答案更新學習單」。尚在作答的題目不寫回。需要於關題後補充正確答案時，在「作答與批改」或「搶答結果」上方選擇已結束的題目，再展開「老師正確答案（選填）」填寫並儲存。儲存後學生立即能在該題看到老師正確答案，並保留於活動結束後的報告；勾選「用老師答案更新學習單」則以「答案（老師答案）」優先寫回。取消勾選並儲存後，恢復最快未判錯組的答案；無有效組別則還原原值。這不會修改學生判定或分數，也不必填寫才能進入下一題。

公開表可直接讀取；私人表及寫回需要老師的 Google 授權。官方原範本僅供試讀，寫回請使用自己的副本。支援單題及題組混合學習單；題組請使用[官方題組範本副本](https://docs.google.com/spreadsheets/d/1PXXwWiBKJNpPkLRoJLMzZWsAh4Jzn2bThHTeRAiq3Hg/copy)。

無人作答的格子保留原值。匯入後若更動題目或列欄，請重新匯入；寫回期間請勿同時編輯原表。

自動同步只處理已關閉題目。題組依交卷順序選用第一份完整且沒有小題被判錯的提交。假如第一組的 1.1 被判錯，1.1 和 1.2 的學生答案與組名會一起換成下一個合格組別。若沒有合格組別，已寫回的學生答案格經核對後還原匯入時的原值。撤銷判錯會依原交卷順序重選，老師指定的答案仍優先。

活動頁會顯示同步中、完成或失敗，失敗後先修正授權／表格問題，再按「重試同步」。老師關閉瀏覽器後，只要伺服器與授權仍有效，倒數關題也會同步。伺服器重啟或登出會失去 Google 連線，請重新授權並開啟活動恢復同步。手動題號活動沒有學習單，不會啟用同步。

若 Google 已收到答案，但網路中斷導致程式未能確認，系統會保留這次寫入紀錄。恢復連線後可重試，即使中途改判或重啟，也會先核對先前寫入，再更新為最新答案；若原格被他人改成不同內容，會停止並保留他人的修改。

自訂版面可在答案格放完整標記，例如 `{{Q:1}}`。標記會在寫回時被答案取代，因此只靠標記定位的學習單，每次建立新活動請使用保留標記的未填寫副本；同一活動內可持續逐題同步。

在副本填入題號與題幹，保留「作答」格供系統寫回。建立活動後，在「題目與計分」將第 1 題設為「多選」，逐行輸入 `2`、`3`、`4` 三個選項，勾選 `2` 和 `3` 為正解，再儲存或開始搶答。選項與正解由活動設定管理。「作答」格會收到課堂結果，請勿先填入解答。[題型設定格式](question-types-api.md)
