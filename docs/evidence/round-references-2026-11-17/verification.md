## 規格與實作對照
| 要求／情境 | 實作與驗證 |
| --- | --- |
| 逐題立即公布 | 學生 references 依共用關題條件過濾，老師儲存後於既有輪詢更新；未作答學生也可查看 |
| 修改、清空與回看 | 題目卡以文字節點呈現最新內容；清空後隱藏，下一題進行中與重新整理後仍能看到先前已公布內容 |
| 未關題保密 | 測試先放入未關題參考答案，學生 API 不包含該題；全題模式直到結束才公布，選擇題答案鍵仍不公開 |
| 組別來源 | _sheet_answers 於匯出邊界加入實際候選組名，相同文字由不同組遞補也更新來源；學生與老師原始答案保持不變 |
| 老師與題組 | 覆蓋顯示老師答案，取消回復組名；題組子題各自依實際來源標示，題組仍由同一成功組提供未覆蓋子題 |
| 舊資料及還原 | 舊無註記 last_export 可核對後更新；全部判錯還原原格，不附加失效標示；外部改格保護仍由既有測試涵蓋 |
