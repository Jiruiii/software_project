- `py -3 -m unittest discover -s tests`：90 項測試全部通過。
- `py -3 tests/run_extra_ui.py --suite auto-sync`：8 項瀏覽器驗收通過，無頁面錯誤，驗證實際寫入序列。
- `py -3 tests/run_extra_ui.py --suite question-types`：簡答／單選與下注／不押的四種組合通過，學生判定與加扣分仍只在關題後公布。
- `py -3 tests/run_live_sheets.py --auto-sync-only`：真實 Google API 的單題原版範本與移動列欄題組均通過。逐輪關題、第一組判錯遞補、全錯還原及重新判對恢復最快組，皆直接讀回雲端儲存格驗證；無關內容與格式保持不變。
- 已檢查桌面與手機截圖：同步狀態可閱讀，教師只保留正確／錯誤操作，手機無水平溢出。

## 規格與實作對照
| 要求／情境 | 實作與驗證 |
| --- | --- |
| E-05 兩種判定 | 教師畫面僅兩個按鈕；API 拒絕 pending；尚未批改簡答保留待批改且不自動加分；批次撤銷仍可恢復先前狀態 |
| F-09 關題自動同步 | 已關閉題目才納入寫回，手動關題、倒數關題與全題模式結束均測試；背景工作不依賴瀏覽器輪詢 |
| 遞補與全錯還原 | 選擇最快未判錯完整提交，題組使用同一組所有子題；全錯恢復匯入原值，改回正確重新恢復最快組 |
| 並行與快速改判 | Google 慢速寫入期間學生可送下一題；中途改判重新同步最新候選；連續判錯後立刻改回亦能恢復已同步狀態 |
| 來源與權限保護 | 原官方範本、來源結構變動、他人改格及權限不足均阻止覆蓋；錯誤顯示與手動重試通過 |
| 授權與重啟恢復 | 授權僅存記憶體；登出／失去授權會提示，重新登入連線並開啟活動可恢復同步；學生無來源或重試權限 |
| 重複操作 | 候選未變不重複請求 Google；待批改改正確且答案未變時保留同步確認；相同值不重複寫入儲存格 |
