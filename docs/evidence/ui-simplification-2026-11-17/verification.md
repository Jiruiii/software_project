# 介面簡化驗收

日期：2026-11-17。變更：`simplify-classroom-ui`。

## 完成內容

- 題目關閉後標示「本題已關閉」，整場完成作答標示「作答結束」；批改分頁只計入已關題待批改答案，零筆不再重複顯示數字。
- Google 同步狀態、錯誤與重試直接可見；長篇說明收合，輪詢保留展開狀態。來源工作表名稱不重複加前綴。
- 縮減標題、老師答案區及分數卡留白；去除手機重複階段導覽、已在批改頁的「前往批改」按鈕。
- 未開放題目只顯示題號與等待狀態，開題自動展開；已送出的下注資訊保留於送出紀錄，不再顯示停用選單。欄位原值與草稿保留，沒有修改學生答案。
- 計分方式可展開，暫時成績仍直接標示；320 px 排行欄位固定適當寬度，避免標題直排。

## 驗證界線

### 文案追補

依使用者確認，學生提示「1 題待關題公布」改為「已送出 1 題，等待本題結束」（全題模式為「等待搶答結束」）；送出紀錄的相同狀態改稱「等待本題結束」。僅調整文案，沿用上述規格的清楚狀態要求，發布時機及分數不變。

只改前端及操作文件，沒有修改後端計分、搶答、分組、資料庫或授權規則。Google 使用記憶體模擬；授權失效畫面以模擬狀態驗證，未存取真實 Google 資料或憑證。
