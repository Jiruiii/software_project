## 規格與實作對照
| 要求／情境 | 實作與驗證 |
| --- | --- |
| 關題後提供老師答案 | reference API 使用共用關題條件；逐題已關閉／全題已結束／倒數到期皆可儲存，未關題、學生及不存在題號遭拒絕 |
| 選填與草稿 | 主要工作區可直接跳過、選回已關題；輪詢和切換題目保留草稿，未儲存不更新資料；儲存失敗保留編輯 |
| 老師答案優先 | _sheet_answers 合併勾選的參考答案並供所有寫回及核對使用；改判不覆蓋老師答案；取消恢復候選或原值 |
| 題組 | 可以只補充一個子題，其他子題維持原成功組，取消覆蓋後整組回到原候選 |
| 權限與分數隔離 | 手動活動只能存參考答案；空白不能勾選寫回；報告仍僅含本組答案；填寫老師答案不改變判定、分數或成功者 |
| 遷移與持久化 | 舊資料新增預設關閉的 reference_override；參考答案原樣保留；重啟後勾選設定與寫回內容一致 |
| 同步與保護 | 寫入期間更改老師答案會重新同步最新內容；他人改格會報錯而不覆蓋；沿用原來源結構與官方範本保護 |

## 使用條件
老師答案不是自動批改指令。Google 寫回需要從自己的學習單匯入活動並連線授權；遇到暫時用量限制時，稍後按「重試同步」。未儲存草稿只在目前頁面保留，重新整理前需按儲存。
