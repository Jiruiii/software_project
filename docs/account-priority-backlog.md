# 全題模式：跨場成績保底（待實作）

教師在準備階段選擇有權查看的已結束活動。當全題開放時，依該場成績及目前參與組別選出並列最低者，優先作答三秒；活動開始後不再因來源成績改判而更動名單。

截至 2026-11-22，逐題模式已依本場分數選出最低組先答三秒。全題模式仍是同時開放，課程排行榜也已能彙總各場分數。跨場保底尚待開發。

帳號版本已在 SQLite 建立課程、小組、成員及場次參與紀錄，管理員、老師與學生已用真實帳號走過一輪；真實助教共同批改尚待驗收。後續可使用同一課程的小組 ID 對應前一場成績。舊版活動只有單場身分，管理員分配課程後仍保留原組別紀錄。[帳號整合進度](../openspec/changes/firebase-course-accounts/tasks.md)

實作前確認重組小組、無前場紀錄與未選來源的規則。驗收需涵蓋資料存取權限、同名不同人、同帳號改名、並列最低、重啟、關題與三秒邊界。
