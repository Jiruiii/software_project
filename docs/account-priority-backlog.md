# 全題模式的跨場保底

授課老師可在活動開始前挑選同課程任一已結束的場次。全題模式預設所有組別同時開始，逐題保底則依本場成績逐題選組。

## 哪些組別可以先答

假設來源場次甲、乙、丙、丁組的已公布總分依序為 −2、−2、4、−5。本場開始時只有甲、乙、丙組和新加入的戊組已進入活動。甲、乙組並列可比組別中的最低分，可以先答任一單題或題組。丙、戊組在開始滿三秒後可答；丁組即使於這三秒內進場，也要等到期滿。

- 以課程內固定小組比對。同組不同成員進場或更改名稱仍可對應；重組後取得新小組 ID 就不會繼承原組成績。
- 有參加來源場次但沒有得分的小組以零分比較。未參加來源場次，或舊紀錄只有組名而無對應身分的小組，均不列入比較。
- 未選來源或沒有任何可比小組時，不設三秒等待期。
- 先答名單與期限在開場時固定。事後改判來源、重新整理或重啟服務都沿用原期限。手動結束或作答時間先到時，依原規則停止收件。

操作步驟見[師生課堂操作](classroom-guide.md)。
