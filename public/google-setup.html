Google 學習單設定

  1. 貼上學習單連結

    在「匯入 Google 學習單」貼上可編輯副本的網址，按「讀取並預覽題號」。需要範本時可先複製單題學習單。

  2. 核對工作表與題號

    有多個分頁時選擇要使用的工作表，確認預覽中的名稱、題號與答案格。

  3. 建立搶答活動

    按「確認題號，建立搶答活動」。逐題模式在關題後自動同步，全題模式在活動結束後同步。後續改判會更新對應小題，可在活動中查看狀態或重試同步。

本機管理員首次設定 Google 連線

  1. 建立 Google Cloud 專案

    使用自己的 Google 帳號開啟 Google Cloud Console，建立專案，例如「課堂搶答」。後續操作都選取這個專案。

  2. 啟用 Google Sheets API

    進入「API 和服務 → 程式庫」，搜尋 Google Sheets API 並啟用。這個程式不需要啟用 Google Drive API。

  3. 設定 Google Auth Platform

    進入「Google Auth Platform」（部分介面稱 OAuth 同意畫面），完成應用程式名稱、支援電子郵件與聯絡電子郵件。個人帳號選 External／外部，保留測試模式，並在 Audience／目標對象把自己的 Google 電子郵件加入測試使用者。

    在 Data Access／資料存取新增範圍 https://www.googleapis.com/auth/spreadsheets。學校帳號可能受管理員政策限制；若無法建立或授權，請依學校規定處理。

  4. 建立「電腦版應用程式」用戶端

    在 Clients／用戶端新增 OAuth 用戶端，選「Desktop app／電腦版應用程式」，下載 JSON。將檔案存放到專案中的 credentials/google-oauth-client.json。如有需要，先建立 credentials 資料夾。

  5. 建立自己的學習單副本並連線

    複製官方單題範本，確認副本由你編輯。啟動課堂搶答、以教師登入，按「連線 Google」，再點「開啟 Google 授權頁」。請用一般 Chrome／Edge，授權剛才加入測試使用者的帳號。看到連線成功後，回原本教師分頁。

    程式使用本機回呼，不需部署網址。若 Google 顯示未驗證提示，先確認應用程式是自己剛建立的專案；拒絕授權可回教師頁重試。

常見狀況

「尚未設定」：檢查副檔名是否被多加成 .json.json，以及檔案是否為電腦版用戶端。

「access_denied」：確認登入的帳號已加入測試使用者，且同意 Sheets 權限。

「權限不足」：確認 Google Sheets API 已啟用、使用同一專案的用戶端，且帳號有原表編輯權限。

重新啟動伺服器或教師登出後，需要再次連線 Google。中斷連線只清除本機授權；也可到 Google 帳號的第三方連線頁撤銷存取。
